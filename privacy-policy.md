# Privacy Policy – Fantasy War Room

Fantasy War Room is a custom GPT that provides fantasy football analysis.

This GPT may use public APIs (such as the Sleeper API) and web browsing to retrieve fantasy football league information when users provide identifiers such as league links, usernames, roster screenshots, or pasted roster text.

No authentication credentials are collected.

No personal data is stored outside of the current chat session. Data is used only to respond to user requests and is not retained after the session ends.

This GPT does not sell, share, or retain user data.
